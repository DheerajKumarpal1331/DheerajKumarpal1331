## 🧭 About me
I build models that catch fraud and price risk in payments. For the last few years I led data science at **Mosambee (a Pine Labs company)**, and before that I was a quantitative analyst at **J.P. Morgan**. I like problems where a model has to be fast, explainable and right on real money.

## 🔭 What I work on
| Area | What it looks like |
|---|---|
| 🛡️ Fraud detection | Real-time scoring, velocity features, anomaly detection |
| 📉 Risk modelling | Transaction and credit risk, monitoring, drift |
| 🏗️ Data platforms | Streaming pipelines and ClickHouse warehouses on payments data |
| 🤖 LLM tooling | Natural-language interfaces over SQL databases |

## 📌 Featured projects
| Project | What it is |
|---|---|
